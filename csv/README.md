# CSV uploads

Put original weather CSV files in this folder. Suggested filename for the July 30, 2026 North Port, Florida data:

`2026-07-30-north-port-weather.csv`

Keep the original column names and values. The `Clock Time` entries should remain exactly as provided; 7:24 AM is when recording was noticed, not necessarily when recording began. The CSV's elapsed `Video Time (s)` is the reliable elapsed-time field. Temperature values are blank in the provided CSV, so they should stay blank unless you have readings to add.

The September 8, 2026 Temecula data can be added here too. Any values reconstructed from chart images should be clearly identified as estimates, not original measurements.
