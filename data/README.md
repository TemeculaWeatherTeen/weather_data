# Reconstructed weather CSVs

These files are approximate digitizations of the plotted traces in the supplied images, not recovered original CSVs. The images show plotted points but do not expose the original raw data or exact timestamps; values and times were estimated from the axes and visible markers. Only trace vertices/key readings are included, so flat runs in the images may have had additional readings not represented here.

Times use ISO 8601 with the `-07:00` PDT offset. CSVs:

- `temperature.csv` — temperature in °C
- `humidity.csv` — relative humidity in %
- `pressure.csv` — pressure in hPa
